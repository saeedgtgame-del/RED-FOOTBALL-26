# RED FOOTBALL 26

نمونه اولیه مرورگری بازی فوتبال با رابط فارسی.

## اجرا
فایل `index.html` را در مرورگر باز کنید. برای انتشار:
1. وارد Settings مخزن شوید.
2. در بخش Pages، گزینه Deploy from a branch را انتخاب کنید.
3. شاخه `main` و پوشه `/(root)` را انتخاب و Save کنید.

## کنترل‌ها
- بازیکن ۱: WASD و Space برای شوت
- بازیکن ۲: کلیدهای جهت‌دار و Enter برای شوت
- در موبایل از دکمه‌های روی صفحه استفاده کنید.

این نسخه نمونه اولیه دوبعدی است؛ گزارش فارسی فعلاً متنی است، نه صوتی.
