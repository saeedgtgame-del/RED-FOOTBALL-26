# RED FOOTBALL 26 — PS2 build

نسخه سه‌بعدی آرکید فوتبال برای PlayStation 2 بر پایه NEXON ENGINE.

## قابلیت‌های این نسخه
- مسابقه ۱۱ در برابر ۱۱ با بازیکنان هندسی سه‌بعدی
- زمین فوتبال با خطوط، دایره وسط، محوطه‌ها و دروازه‌ها
- سکوهای استادیوم
- هوش مصنوعی پایه برای هر دو تیم و تعقیب توپ
- فیزیک پایه توپ شامل سرعت، اصطکاک، پرش و برخورد
- دوربین مشترک استادیومی
- امتیاز، زمان مسابقه، شروع، مکث و پایان
- اتصال به NEXON ENGINE برای مدیریت صحنه، موجودیت‌ها و زمان

## کنترل دسته PS2
- آنالوگ چپ یا کلیدهای جهت: حرکت
- مربع: پاس
- دایره: شوت
- مثلث: تعویض بازیکن
- ضربدر: دویدن سریع
- START: شروع / مکث

## دریافت فایل ELF
هر بار که کد به شاخه main ارسال شود، GitHub Actions تلاش می‌کند فایل PS2 را بسازد.
پس از پایان موفق اجرا:
1. وارد تب Actions مخزن شو.
2. آخرین اجرای «Build RED FOOTBALL 26 PS2» را باز کن.
3. در بخش Artifacts، فایل `RED-FOOTBALL-26-PS2` را دریافت کن.

## وضعیت صادقانه پروژه
این یک نسخه قابل‌بازی پایه با گرافیک هندسی است؛ هنوز هم‌سطح PES 2016 نیست. گزارش صوتی فارسی، چهره‌ها و انیمیشن‌های حرفه‌ای، لیگ/جام و دو نفره با دو دسته در این بیلد وجود ندارند و باید در نسخه‌های بعدی اضافه شوند.
